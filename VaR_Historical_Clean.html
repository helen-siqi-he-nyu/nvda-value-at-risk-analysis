Value at Risk (VaR) — Historical Method (Clean Notebook)

This notebook computes Value at Risk (VaR) using the Historical (Non‑Parametric) approach.

What you will do

  • Choose a stock ticker (e.g., AAPL, MSFT, NVDA).
  • Download daily adjusted close prices.
  • Compute daily returns.
  • Estimate VaR using the empirical quantile of historical returns:
    • Daily VaR
    • Horizon VaR (e.g., 30‑day) using rolling compounded returns (historically consistent).

Key idea (Historical VaR)

Historical VaR does not assume Normality. It uses the return distribution observed in the sample. For confidence level (c), the VaR threshold is the ((1-c)) lower tail quantile of returns.

Convention used here: VaR is reported as a negative return (a loss threshold). Dollar VaR is therefore typically negative as well.

2) Download data and compute returns

We download Adjusted Close prices and compute:

  • Simple return: (R_t = \frac{P_t - P_{t-1}}{P_{t-1}})

For Historical VaR, we will use simple returns (most intuitive for students).

raw = yf.download(TICKER, start=START, end=END, progress=False, auto_adjust=False)

# Keep Adj Close only and rename
df = raw[["Adj Close"]].rename(columns={"Adj Close": "adj_close"}).copy()

# Compute returns
df["simple_rtn"] = df["adj_close"].pct_change()

# Drop first NA return
df = df.dropna()

4) Historical VaR — Daily

For confidence level (c), daily historical VaR is the empirical ((1-c)) quantile of daily returns.

  • 95% VaR → 5th percentile of daily returns
  • 99% VaR → 1st percentile of daily returns

We also compute Dollar VaR for an initial investment value.

In [5]:
# =========================
# 4) Historical VaR (Daily)
# =========================
results_daily = []

for c in CONF_LEVELS:
    alpha = 1 - c
    var_r = np.percentile(df["simple_rtn"], 100 * alpha)   # lower tail quantile
    var_usd = INITIAL_INV * var_r

    results_daily.append({
        "Confidence": f"{int(c*100)}%",
        "Daily VaR (return)": var_r,
        "Daily VaR ($)": var_usd
    })


daily_table = pd.DataFrame(results_daily)

5) Historical VaR — Horizon (Rolling Compounded Returns)

A common mistake is to scale VaR by (\sqrt{T}). That is a parametric approximation that implicitly assumes i.i.d. Normal returns.

For Historical VaR, the historically consistent approach is to construct rolling horizon returns using compounding:

[ R_{t,t+H} = \prod_{j=1}^{H} (1 + R_{t+j}) - 1 ]

Then take the same lower‑tail quantile of these horizon returns.

# =========================
# 5) Historical VaR (Horizon) via rolling compounded returns
# =========================
gross = (1 + df["simple_rtn"])

# Rolling product of gross returns over HORIZON_DAYS
rolling_gross = gross.rolling(HORIZON_DAYS).apply(np.prod, raw=True)
horizon_rtn = (rolling_gross - 1).dropna()

results_h = []
for c in CONF_LEVELS:
    alpha = 1 - c

    # <-- THIS LINE WAS MISSING
    var_h = np.percentile(horizon_rtn, 100 * alpha)

        f"{HORIZON_DAYS}-day VaR (return)": var_h,
