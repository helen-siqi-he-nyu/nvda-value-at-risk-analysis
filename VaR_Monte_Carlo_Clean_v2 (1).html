Value at Risk (VaR) — Monte Carlo Simulation Method¶

This notebook computes Value at Risk (VaR) using a Monte Carlo simulation approach.

What you will do¶

  • Choose a stock ticker (e.g., AAPL, MSFT, NVDA).
  • Download daily Adjusted Close prices.
  • Compute daily simple returns.
  • Estimate return parameters from historical data.
  • Simulate future returns under a parametric model (Normal i.i.d.).
  • Compute Monte Carlo VaR for:
    • Daily horizon
    • Multi‑day horizon (e.g., 30 days)

Key idea (Monte Carlo VaR)¶

Rather than computing VaR analytically, we:

  1. Assume a data‑generating process for returns (here: Normal i.i.d.).
  2. Simulate many possible outcomes (or paths).
  3. Estimate VaR as the empirical lower‑tail quantile of simulated returns.

Convention used here: VaR is reported as a negative return (loss threshold). Dollar VaR is therefore typically negative as well.

4) Monte Carlo simulation — Daily VaR¶

We simulate daily returns from the assumed distribution and compute VaR as the empirical lower‑tail quantile of simulated returns.

In [5]:
# =========================
# 4) Simulate daily returns
# =========================
rng = np.random.default_rng(42)  # reproducibility
sim_daily = rng.normal(loc=mu_hat, scale=sigma_hat, size=N_SIM)

# Compute daily VaR (return and $)
results_daily = []
for c in CONF_LEVELS:
    alpha = 1 - c
    var_r = np.percentile(sim_daily, 100 * alpha)
    var_usd = INITIAL_INV * var_r

    results_daily.append({
        "Confidence": f"{int(c*100)}%",
        "Daily VaR (return)": var_r,
        "Daily VaR ($)": var_usd
    })

daily_table = pd.DataFrame(results_daily)

5) Monte Carlo simulation — Horizon VaR¶

To compute horizon VaR, we simulate paths of daily returns and compound them to form horizon returns:

[ R_{t,t+H} = \prod_{j=1}^{H} (1 + R_{t+j}) - 1 ]

VaR is computed from the simulated horizon‑return distribution.

In [7]:
# =========================
# 5) Simulate return paths and compute horizon returns
# =========================
# Simulate daily return paths: shape = (N_SIM, HORIZON_DAYS)
sim_paths = rng.normal(loc=mu_hat, scale=sigma_hat, size=(N_SIM, HORIZON_DAYS))

# Compound returns along each path to get H-day return
sim_horizon = np.prod(1 + sim_paths, axis=1) - 1

# Compute horizon VaR (return and $)
results_h = []
for c in CONF_LEVELS:
    alpha = 1 - c
    var_h = np.percentile(sim_horizon, 100 * alpha)
    var_h_usd = INITIAL_INV * var_h

    results_h.append({
        "Confidence": f"{int(c*100)}%",
        f"{HORIZON_DAYS}-day VaR (return)": var_h,
        f"{HORIZON_DAYS}-day VaR ($)": var_h_usd
    })

horizon_table = pd.DataFrame(results_h)
horizon_table

Q1. What does VaR measure?¶

Value at Risk is a loss threshold for a specified holding period and confidence level. For example, Historical 95% daily VaR for this USD 100,000 NVDA position is a return threshold of −4.8350%, or a loss of USD 4,835.04. If the historical distribution remains representative, about 5% of daily outcomes would be worse than this threshold, while about 95% would not. At 99% confidence, the estimated daily loss threshold rises to USD 7,610.08, with a 1% probability of a worse outcome under the estimated distribution.

VaR does not give the maximum possible loss or the average loss in the worst cases. It says nothing about how severe a loss will be once the threshold is exceeded. It is also an estimate conditional on the sample and model, not a guarantee about future outcomes.

Q2. Historical vs. Parametric VaR¶

The daily tables show that the Normal method gives a larger loss threshold at 95%: USD 5,147.01 versus the Historical estimate of USD 4,835.04. At 99%, the ranking reverses: Historical VaR is USD 7,610.08, compared with USD 7,389.86 for the Normal method. Thus, the Normal method is not uniformly more conservative. For 30 days, the Normal estimates exceed the Historical estimates at both confidence levels: USD 21,660.27 versus USD 20,965.06 at 95%, and USD 33,944.86 versus USD 33,155.42 at 99%.

Historical VaR uses empirical return quantiles and preserves the sample's distributional shape, including observed extreme returns. Parametric VaR fits a symmetric Normal distribution using only the estimated daily mean (approximately 0.2663%) and standard deviation (3.2911%). That model need not match the observed quantiles at every confidence level. The parametric horizon calculation additionally assumes independent, identically distributed returns with constant parameters and approximates the horizon return using H times the mean and the square root of H times the standard deviation. Historical horizon VaR instead uses actual rolling compounded 30-day returns. Historical VaR does not require Normality, but it still relies on the observed period being informative about future risk and cannot represent unseen extremes well.

Q3. Distribution Shape and Tail Risk¶

The Historical daily histogram has a strong concentration near zero, with a small number of returns far from the center, including a negative return near −17% and positive returns above 20%. The Parametric daily histogram and Normal overlay show that a smooth symmetric model does not fully capture these extreme observations. The 99% Historical cutoff is also farther into the loss tail than the 99% Normal cutoff. These features suggest departures from Normality and meaningful tail risk; the histogram alone is not a formal distribution test.

A Normal-based model can understate extreme risk if real returns have heavier loss tails, abrupt jumps, or periods of elevated volatility that are diluted by full-sample parameter estimates. It can also overstate risk at a particular percentile: in this sample, the 95% Normal daily threshold is more negative than the Historical threshold. A volatility estimate dominated by turbulent periods may likewise overstate risk in a quieter period. The two confidence levels illustrate why the direction of the difference depends on the percentile, sample, and market conditions.

Q4. Monte Carlo VaR Interpretation¶

The required Monte Carlo notebook simulates simple daily returns from a Normal distribution using NVDA's estimated historical mean and standard deviation. It first generates 100,000 daily returns. It then generates 100,000 paths, each containing 30 daily returns, and compounds each path as the product of (1 + daily return), minus one. VaR is the appropriate lower-tail percentile of the simulated daily or compounded horizon outcomes.

Historical VaR uses realized observations; Parametric VaR calculates a theoretical Normal quantile analytically; Monte Carlo VaR estimates quantiles from generated scenarios. Here the simulation assumes independent, identically distributed Normal daily returns and constant mean and volatility. It does not explicitly model volatility clustering, jumps, or changing regimes. Increasing the simulation count reduces sampling noise but does not remove these model limitations.

The daily Monte Carlo and Parametric estimates are close because they use the same Normal model. Their 99% daily losses are USD 7,446.35 and USD 7,389.86; finite simulation sampling explains the difference. At 30 days, Monte Carlo gives USD 30,179.38 versus the Parametric estimate of USD 33,944.86. Exact compounding in the simulation produces a different horizon distribution from the additive Normal approximation, so the horizon difference is not just simulation noise. The optional GBM notebook was not used.

Q5. Horizon Risk¶

Across all three methods, 30-day VaR has a greater loss magnitude than daily VaR. For example, Historical 95% VaR rises from USD 4,835.04 to USD 20,965.06; Monte Carlo 99% VaR rises from USD 7,446.35 to USD 30,179.38. Over a longer holding period, more daily shocks accumulate and the range of possible outcomes generally widens. The positive estimated mean offsets part of the downside in this sample, so VaR does not have to increase monotonically for every model or every possible horizon.

Multiplying daily VaR by 30 would treat the one-day tail threshold as if it occurred on every day. Quantiles do not add that way: gains and losses can offset. Under the notebook's i.i.d. Normal approximation, variance grows with H and standard deviation with the square root of H, while the mean grows with H. Even this does not make horizon VaR exactly the square root of H times daily VaR when the mean is nonzero.

Compounding applies each return to the updated investment value. For example, a 10% gain followed by a 10% loss produces 1.10 × 0.90 − 1 = −1%, rather than zero. Historical and Monte Carlo horizon calculations use this product directly. The Historical approach uses observed rolling windows, retaining the actual within-window sequence of returns; the Monte Carlo approach uses independent simulated daily shocks. The overlapping Historical windows are not independent observations, which limits how precisely their tail quantiles can be estimated.
