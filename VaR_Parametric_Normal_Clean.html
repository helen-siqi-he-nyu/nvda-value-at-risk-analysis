Value at Risk (VaR) — Parametric (Normal) Method (Clean Notebook)

This notebook computes Value at Risk (VaR) using the Parametric (Normal) approach.

What you will do

  • Choose a stock ticker (e.g., AAPL, MSFT, NVDA).
  • Download daily adjusted close prices.
  • Compute daily simple returns.
  • Estimate Parametric VaR assuming returns are Normally distributed:
    • Daily VaR
    • Horizon VaR (e.g., 30‑day) using the Normal i.i.d. scaling rule

Key idea (Parametric Normal VaR)

If daily returns are modeled as: [ R \sim \mathcal{N}(\mu, \sigma^2), ] then the ((1-c)) left‑tail quantile is: [ q_{1-c} = \mu + \sigma, z_{1-c}, ] where (z_{1-c}) is the standard Normal quantile (e.g., (z_{0.05}\approx -1.645)).

Convention used here: VaR is reported as a negative return (loss threshold). Dollar VaR is therefore typically negative as well.

3) Estimate Normal parameters ((\mu), (\sigma))

Parametric VaR depends on the mean and volatility of returns. We estimate:

  • (\hat\mu) = sample mean of daily returns
  • (\hat\sigma) = sample standard deviation of daily returns

sigma_hat = df["simple_rtn"].std(ddof=1)

4) Parametric VaR — Daily

For confidence level (c), let (\alpha=1-c). The Normal left‑tail quantile is: [ \text{VaR}{c,1} = \mu + \sigma, z{\alpha}. ]

We also compute Dollar VaR for a portfolio value.

In [5]:
# =========================
# 4) Parametric VaR (Daily)
# =========================
results_daily = []

for c in CONF_LEVELS:
    alpha = 1 - c
    z = norm.ppf(alpha)  # e.g., ppf(0.05) ~ -1.645
    var_r = mu_hat + sigma_hat * z
    var_usd = INITIAL_INV * var_r

    results_daily.append({
        "Confidence": f"{int(c*100)}%",
        "Daily VaR (return)": var_r,
        "Daily VaR ($)": var_usd,
        "z_(1-c)": z
    })

daily_table = pd.DataFrame(results_daily)
daily_table

5) Parametric VaR — Horizon (Normal i.i.d. scaling)

Under the i.i.d. Normal model, the (H)-day return is approximately Normal with:

  • Mean: (\mu_H = H\mu)
  • Std dev: (\sigma_H = \sqrt{H}\sigma)

So: [ \text{VaR}{c,H} = \mu_H + \sigma_H, z{\alpha}. ]

This (\sqrt{H}) scaling is a parametric assumption and differs from the rolling-compounding approach used for Historical VaR.

In [6]:
# =========================
# 5) Parametric VaR (Horizon)
# =========================
H = HORIZON_DAYS
mu_H = H * mu_hat
sigma_H = np.sqrt(H) * sigma_hat

results_h = []
for c in CONF_LEVELS:
    alpha = 1 - c
    z = norm.ppf(alpha)
    var_h = mu_H + sigma_H * z
    var_h_usd = INITIAL_INV * var_h

    results_h.append({
        "Confidence": f"{int(c*100)}%",
        f"{H}-day VaR (return)": var_h,
        f"{H}-day VaR ($)": var_h_usd,
        "z_(1-c)": z
    })

horizon_table = pd.DataFrame(results_h)
horizon_table

6) Visualize VaR on the return distribution (Daily)

We overlay the Normal density implied by (\hat\mu) and (\hat\sigma), and draw vertical lines at the VaR cutoffs.

In [7]:
# =========================
# 6) Histogram + Normal overlay + VaR cutoffs (Daily)
# =========================
x = np.linspace(df["simple_rtn"].min(), df["simple_rtn"].max(), 600)
pdf = norm.pdf(x, loc=mu_hat, scale=sigma_hat)

plt.figure(figsize=(9,4))
plt.hist(df["simple_rtn"], bins=60, density=True, edgecolor="black", alpha=0.75, label="Daily returns (hist)")
plt.plot(x, pdf, linewidth=2, label="Normal fit (PDF)")

for c in CONF_LEVELS:
    alpha = 1 - c
    var_r = mu_hat + sigma_hat * norm.ppf(alpha)
    plt.axvline(var_r, linestyle="--", linewidth=2, label=f"{int(c*100)}% VaR")

plt.title(f"{TICKER}: Daily Returns with Parametric (Normal) VaR Cutoffs")
plt.xlabel("Daily return")
plt.ylabel("Density")
plt.legend()
plt.tight_layout()
plt.show()

7) Visualize Horizon VaR (Optional)

To visualize the parametric horizon distribution, we plot the Normal density for (H)-day returns and the horizon VaR cutoffs.

# =========================
# 7) Normal density + VaR cutoffs (Horizon)
# =========================
H = HORIZON_DAYS
mu_H = H * mu_hat
sigma_H = np.sqrt(H) * sigma_hat

xH = np.linspace(mu_H - 4*sigma_H, mu_H + 4*sigma_H, 600)
pdfH = norm.pdf(xH, loc=mu_H, scale=sigma_H)

plt.figure(figsize=(9,4))
plt.plot(xH, pdfH, linewidth=2, label=f"Normal model for {H}-day return")

for c in CONF_LEVELS:
    alpha = 1 - c
